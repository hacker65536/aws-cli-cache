# コーディング標準

Google Shell Style Guide に準拠したコーディング標準。

## 関数コメント形式

```bash
#######################################
# 関数の説明
# Globals:
#   VARIABLE_NAME - 説明
# Arguments:
#   $1 - 説明
# Outputs:
#   stdout/stderrへの出力説明
# Returns:
#   0 成功, 1 失敗
#######################################
```

## 必須ルール

1. **テスト構文**: `[[ ]]`を使用
2. **変数引用**: `"${var}"`形式
3. **main 関数**: エントリーポイントは`main()`
4. **ローカル変数**: 関数内は`local`使用
5. **エラー処理**: `||`や`&&`で適切に処理

## 品質基準

- 関数: 50 行以内
- コメント率: 25%以上
- Shellcheck 警告: 最小限
